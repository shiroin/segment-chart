GoogleスプレッドシートのURLを貼って「読み込む」。売上高・利益（四半期／年度）のシートと segments / config を自動で判別します。Claudeの「Google Sheets」連携を使い、見ている人の権限で読み込みます。
スプレッドシートで「ファイル → 共有 → ウェブに公開」→「ドキュメント全体」「Microsoft Excel (.xlsx)」で発行したURLを貼ってください。読み込んだシートはページのURLに記録されるので、ブックマークや共有ができます。

企業マスターから会社を選ぶと、各社の Financials（会社全体_四半期／年度）を読み込み、全社の売上高・営業利益を並べて比較します。

この版（GitHub Pages）では各社の Financials を直接読めないため、会社比較は Claude 上のページか Apps Script 版で使えます。
