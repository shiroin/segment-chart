# セグメント業績チャート

Googleスプレッドシートのセグメント別業績（売上高・セグメント利益）を、軸をそろえたグラフで比較表示するWebアプリです。

**公開URL:** https://shiroin.github.io/segment-chart/

## 使い方

1. `segment_chart_template.xlsx` を Google ドライブにアップロードし、「Google スプレッドシートとして保存」する
2. 数字を入力する（下の「シート構成」）
3. スプレッドシートで **ファイル → 共有 → ウェブに公開** を開き、
   「ドキュメント全体」「Microsoft Excel (.xlsx)」を選んで **公開**
4. 表示された URL（`https://docs.google.com/spreadsheets/d/e/…`）をアプリの「Googleシート」欄に貼って「読み込む」
5. ページの URL が `?sheet=…` 付きに変わるので、会社ごとにブックマーク

> 「ウェブに公開」すると、そのURLを知っている人はシートの数字を見られます。公開情報（IRデータ）向けです。
> シートの変更がアプリに反映されるまで、数分かかることがあります。

## シート構成（シート名は自由。中身で自動判別）

| シート | 内容 |
| --- | --- |
| config | 企業名・タイトル・通貨・データの単位・表示単位・注記・表示区分など（項目 / 値） |
| segments | セグメントごとの表示名・サブタイトル・色・表示（行の順＝グラフの並び順） |
| セグメント売上高_四半期 | A列 `period`（FY2025 Q1 など）、B列以降がセグメント |
| セグメント売上高_年度 | A列 `period`（FY2025 など）、B列以降がセグメント |
| セグメント利益_四半期 | 同上 |
| セグメント利益_年度 | 同上 |

売上高と利益は、同じ period・同じセグメント名どうしで組み合わされます。
シート名（または1行目のタイトル）に「売上／利益」「四半期／年度」を含めてください。

## 主な機能

- 四半期 / 年度 の切り替え、表示期間の調整、抜けている期の空欄表示
- セグメント数・期数に制限なし、色・並び順・表示の切り替え
- 通貨（円・USD・EUR・TWD・HKD・KRW・DKK ほか）と表示単位（百万・億・十億・兆）、為替換算
- 縦横比・サイズの指定、PNG / SVG 書き出し
